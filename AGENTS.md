# AGENTS.md

This repository contains the NVIDIA Run:ai product documentation, rendered by
[Fern](https://buildwithfern.com) at
`nvidia-runai-self-hosted.docs.buildwithfern.com`.

NVIDIA Run:ai is an open-source GPU orchestration and optimization platform for
AI, built on Kubernetes. It supports dynamic GPU allocation, workload submission,
scheduling, and resource sharing — enabling AI teams to maximize GPU utilization
while IT teams maintain infrastructure control.

## Documentation

Do not proactively edit anything under `docs/` (the user-facing product
documentation) as a side effect of a code change, even if the change affects
a user-visible surface. Only update `docs/` when explicitly asked to in the
task.

When explicitly asked to update `docs/`:

1. Read `docs/AGENTS.md` before editing.
2. Locate and update the affected pages under `docs/`, and run `fern docs dev`
   to validate the result.
