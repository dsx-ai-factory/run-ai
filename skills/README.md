# Run:ai Agent Skills

Agent Skills for the Run:ai platform — pre-built, evaluated workflows that teach an
AI agent (Claude Code, Codex, Cursor, …) how a Run:ai expert performs an operational
task on top of the Run:ai MCP tools. They follow the [agentskills.io](https://agentskills.io/specification)
spec and are intended for publication to **github.com/nvidia/skills** via the NVCARPS
pipeline once Run:ai is open-sourced.

## Layout
One directory per skill:

```text
skills/<skill-name>/
├── SKILL.md            # frontmatter (name + trigger-rich description) + workflow
├── references/         # deep-dive domain knowledge, loaded on demand
├── evals/
│   ├── evals.json      # trigger + output-quality test cases (agentskills schema)
│   ├── files/          # inputs staged into the eval sandbox (e.g. a mock MCP server)
│   └── environment/    # Tier 3 container config (mcp_servers.toml, …)
└── BENCHMARK.md        # NVSkills-Eval results (with-skill vs baseline)
```
`LICENSE` lives at the `skills/` root; `skill-card.md` (the trust manifest) is
auto-generated by NVCARPS at publish time.

## Skills
- **runai-audit-assigned-quota** — audit GPU quota fairness (starved vs over-borrowing
  per node pool, cause = borrowing vs over-subscription, and the correct fix). Read-only.
