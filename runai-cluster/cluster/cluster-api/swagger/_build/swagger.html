K8sObject

Get the k8s object of a workload

Returns a point-in-time snapshot of the workload's top-level Kubernetes custom resource, as read from the Kubernetes API server. The response is sanitized and wrapped with the retrieval timestamp.

Authorizations:
bearerAuth
path Parameters
workloadId
required
string <uuid>

The unique identifier (UUID) of the workload.

Responses

http://localhost:8080/cluster-api/api/v2/workloads/{workloadId}/object
