# external-workload-integrator

The external-workload-integrator will observe all kinds of 3-rd party workloads
we support, and create an externalworkload.run.ai object for each of them.
Later the cluster-sync will sync those objects back to the control-plane.

You can read more here -
https://runai.atlassian.net/wiki/spaces/EN/pages/2636447749/Design+-+new+workloads+sync+-+operator+-+new+service+and+crd .
