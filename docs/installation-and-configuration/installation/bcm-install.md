# Install Using Base Command Manager (BCM)

<Info>

**Note**

NVIDIA Run:ai version 2.25 is not yet available through NVIDIA Base Command Manager (BCM).

NVIDIA Base Command Manager (BCM) currently supports NVIDIA Run:ai versions [2.23](https://app.gitbook.com/s/fvuZQSF7VCx1Azh0LF0H/getting-started/installation/bcm-install) and [2.22](https://app.gitbook.com/s/lZD4O0TqiQ8mlhnxho0w/getting-started/installation/bcm-install). If you are deploying through BCM, refer to the BCM-specific installation instructions for these supported releases.

</Info>
