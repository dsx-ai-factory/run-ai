A compute resource is a building block that represents compute resources such as GPUs, CPU cores, and CPU memory.
The compute resources may consist of multiple physical resources, for example, 0.5 GPU, 8 cores and 200 Megabytes of CPU memory.
A compute resource is available to a scope and and all of the organizational units within that scope.

For more information, see [Compute resource](/run-ai/self-hosted/documentation/workloads-in-nvidia-run-ai/assets/compute-resources).
