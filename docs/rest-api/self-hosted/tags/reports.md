Reports provide data on resource consumption, such as GPU, CPU, and CPU memory, across organizational units, as a CSV file. For more information, see [Reports](/run-ai/self-hosted/documentation/platform-management/monitor-performance/reports).

Use the Reports endpoints to create a report request, list and count reports, retrieve a report, download a report as a file, and delete reports one at a time or in a batch. You can also check whether reports are available.

## Creating a Report

To create a report, set a name and a start and end time. You can also add a description, filter the data by project, department, or cluster, and group it by node pool, project, department, or cluster.

## Report Status

A report is processed after you create it. Check its status, and download the file when the status is `Ready`.
