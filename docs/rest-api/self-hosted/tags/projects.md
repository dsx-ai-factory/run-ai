Projects implement resource allocation policies and create segregation between
different initiatives. It can represent a team, an individual, or an initiative that
shares resources or has a specific resources budget (quota).
See [Projects](/run-ai/self-hosted/documentation/platform-management/manage-ai-initiatives/organization/projects)
for more information.

Use the Projects endpoints to create, list, retrieve, update, delete, and count projects.

## Project Resources

Update the resources of a project, or patch only the node pools included in the request while the other node pools stay unchanged. You can also list and count the node pool resources of projects, and patch node pool resource quotas for multiple projects in a single batch request.

## Project Telemetry and Metrics

Retrieve telemetry for projects, and retrieve metrics data for a single project for use in reporting and analysis tools.
