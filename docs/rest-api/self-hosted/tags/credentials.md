Credentials are used to unlock protected resources such as applications, containers, and other assets. For more information, see [Credentials](/run-ai/self-hosted/documentation/workloads-in-nvidia-run-ai/assets/credentials).

Use the Credentials endpoints to list all credentials, and to create, list, retrieve, update, and delete credentials of each type.

## Credential Types

* **Access key** - An S3-compatible access key.
* **Password** - A user ID and password.
* **Docker registry** - A user ID, password, and URL for a Docker registry.
* **Generic secret** - A generic secret.
* **NGC API key** - An NGC API key.
