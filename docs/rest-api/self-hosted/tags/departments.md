Departments, in the hierarchy of resource allocation, are above Projects. A Department can contain multiple Projects, and has its own quotas.
A Department's quota supersedes the total of the Project quotas in the Department, so it is recommended that a Department's quota be the total, or more than of all the Project quotas in the Department.
For further information see, [Working with Departments](/run-ai/self-hosted/documentation/platform-management/manage-ai-initiatives/organization/departments).

Use the Departments endpoints to create, list, retrieve, update, delete, and count departments.

## Department Resources

Update the resources of a department, or patch only the node pools included in the request while the other node pools stay unchanged. You can also list and count the node pool resources of departments, and patch node pool resource quotas for multiple departments in a single batch request.

## Department Telemetry and Metrics

Retrieve telemetry for departments, and retrieve metrics data for a single department for use in reporting and analysis tools.
