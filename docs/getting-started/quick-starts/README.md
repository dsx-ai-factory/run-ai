# Quick Start Guides

This quick start helps you get up and running with NVIDIA Run:ai by guiding you through the main stages of platform adoption, from deployment through day-to-day workload execution.

## Deploy Infrastructure

Follow the instructions in the [Deploy Infrastructure Quick Start](deploy-infrastructure-quick-start.md) to install NVIDIA Run:ai and complete the required post-installation infrastructure setup.

## Configure the Platform

Follow the instructions in the [Configure the Platform Quick Start](configure-the-platform-quick-start.md) to complete the onboarding wizard, configure authentication and organizational structure, and prepare the platform for teams to run workloads.

## Run Workloads

Follow the instructions in the [Run Workloads Quick Start](run-workloads-quick-start.md) to log in, select a project, and run experiments and production workloads on NVIDIA Run:ai.
