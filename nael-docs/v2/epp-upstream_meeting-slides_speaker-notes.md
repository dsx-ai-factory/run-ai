## מילון קצר למונחים שעלולים לעצור את השיחה

| מונח בשקפים | במילים פשוטות |
|---|---|
| discrete | בוחרים אחד מכמה פרופילים מוכנים, במקום לחשב משקל רציף |
| band / stay band | התחום בין סף היציאה (0.35) לסף הכניסה (0.5); בתוכו לא משנים החלטה |
| cv | סטיית תקן חלקי ממוצע של התורים; "כמה לא אחיד" |
| P | ממתינות חלקי (ממתינות + רצות); "איזה חלק מהעבודה מחכה" |
| gate (`minMeanQueue`) | מתחת לממוצע תור 3, cv נחשב 0: אין מה לפזר |
| portable / no retuning per pool | אותם ספים נכונים לכל מודל ו‑GPU, כי הם יחסים ולא מספרי בקשות |
| prefix index | ה"מחברת" של ה‑EPP: לאיזה פוד שלחנו כל תחילת prompt; לא שואלים את vLLM |
| plugin | כל רכיב מתחבר ב‑EPP: filter, scorer, picker, data producer, profile handler… |
| profile handler | סוג אחד של plugin: מחליט איזה פרופיל ירוץ ומעבד את התוצאה. מותר **אחד** בלבד ב‑EPP |
| adaptive‑profile‑handler | ה‑profile handler שלנו. instance אחד שמממש גם DataProducer (צעד 6) וגם ProfileHandler (צעדים 8, 10) |

🧠 **לזכור את זה כ:** היום דביק מדי לפוד; ההצעה דביקה לפרופיל עד שיש סיבה.
