Auth

Validate JWT and return identity headers

ForwardAuth endpoint called by Traefik for every protected request. Validates the Bearer JWT against Keycloak, then returns the nine X-Runai-* identity headers that Traefik copies onto the upstream request.

Tenant

Resolve tenant ID from the request hostname

ForwardAuth endpoint called by Traefik for hostname-scoped routes. Resolves the tenant name from the forwarded hostname via tenants-manager and returns the X-Runai-Tenant-Id header that Traefik copies onto the upstream request. Always returns 200 — when the tenant cannot be resolved the request passes through without the header.

Authorizations:
bearerAuth
header Parameters
X-Forwarded-Host
string <= 253 characters ^[a-zA-Z0-9.-]+(:[0-9]+)?$

Hostname of the original client request, set by Traefik.

Responses

http://localhost:8181/internal/plugins/extract-tenant-id

Redirect Validation

Validate the OAuth redirect_uri for workload auth flows

ForwardAuth endpoint for the workload-redirect-validation Traefik middleware. Validates the redirect_uri query parameter against the cluster's registered external URL. Returns 200 when the URI is valid so Traefik forwards the request to Keycloak; returns 400 + HTML error page when invalid — Traefik forwardAuth passes non-2xx responses directly to the client.

Authorizations:
bearerAuth
query Parameters
redirect_uri
required
string
