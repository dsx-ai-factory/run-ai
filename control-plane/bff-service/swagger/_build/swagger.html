Update appearance setting by key

Authorizations:
bearerAuth
path Parameters
key
required
string (appearanceSettingsKeyEnum)
Value: "bannerConfig"

The appearance setting key

query Parameters
tenantId
string
Default: ""
Example: tenantId=1008

If exists will return the relevant resource for the tenant ID

Request Body schema: application/json
required
Any of
enabled
boolean or null

Whether the banner is displayed at the top of the UI for all authenticated users.

text
string or null <= 500 characters

Message displayed in the banner. Required when enabled is true. Maximum 500 characters.

backgroundColor
string or null <= 50 characters

Background color of the banner. Accepts any valid CSS color value (hex, rgb, named). Maximum 50 characters.

fontColor
string or null <= 50 characters

Text color of the banner. Accepts any valid CSS color value (hex, rgb, named). Maximum 50 characters.

fontSize
integer or null [ 1 .. 20 ]

Font size in pixels. Maximum 20. Defaults to 14 if omitted or null.

Responses

http://localhost:8080/api/v1/ui-appearance/settings/{key}
