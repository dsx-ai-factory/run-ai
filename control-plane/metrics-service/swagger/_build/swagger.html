Reports

List reports

Authorizations:
bearerAuth
query Parameters
filterBy
Array of strings <= 10 items [^(name|createdAt|createdBy|status)(==|!=|<=|>...]
Example: filterBy=name!=some-name

Filter results by a parameter. Use the format field-name operator value. Operators are == Equals, != Not equals, <= Less than or equal, >= Greater than or equal, =@ contains, !@ Does not contains, =^ Starts with and =$ Ends with. Dates are in ISO 8601 timestamp format and available for operators ==, !=, <= and >=.

sortBy
string (ReportFilterAndSortFields)
Enum: "name" "createdAt" "createdBy" "status"

Sort results by a parameters.

sortOrder
string
Default: "asc"
Enum: "asc" "desc"

Sort results in descending or ascending order.

offset
integer <int32>
Example: offset=100

The offset of the first item returned in the collection.

limit
integer <int32> [ 1 .. 500 ]
Default: 50

The maximum number of entries to return.

search
string
Example: search=test project

Filter results by a free text search.

MetricStores

Create/Save metric store for tenant

Create metric store for tenant or save an existing one

Authorizations:
bearerAuth
Request Body schema: application/json
required

metrics store

tenantId
required
integer <int32>

The id of the tenant.

datasourceId
string <= 255 characters

Id of the datasource. Optional - when empty, the metrics-service either (a) generates a new datasource via the configured provider when metricStoreDetails is null, or (b) saves an external metric store with datasourceId="external" when metricStoreDetails is provided.

object or null (MetricStoreDetails)

Optional on create requests; always populated on responses. When null on create, the metrics-service generates the metric store via the configured datasource provider.

Responses

http://localhost:8080/internal/metric-stores
