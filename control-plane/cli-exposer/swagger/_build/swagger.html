Get CLI latest version

This endpoint compares the latest version of the CLI with the current local version. If the local version is outdated, the endpoint returns the latest version.

Authorizations:
bearerAuth

Responses

http://localhost:8080/api/v1/cli-exposer/version

Response samples

  • 200
  • 400
  • 401
  • 404
  • 500
  • 503
Content type
application/json
{
  • "sdkVersion": "2.0.0",
  • "cpVersion": "2.50.0",
  • "needUpgrade": false
}

Download RunAI Researcher command line binary

This endpoint returns a binary file that run the Run:ai CLI.

Authorizations:
bearerAuth
path Parameters
operatingSystem
required
string [ 4 .. 7 ] characters
Enum: "linux" "windows" "darwin"
Example: linux

The operating system name.

architecture
required
string [ 4 .. 10 ] characters
Example: arm64

The architecture type.

Responses

http://localhost:8080/api/v1/cli-exposer/dist/{operatingSystem}/{architecture}/runai

Response samples

  • 200
  • 401
  • 404
  • 500
  • 503
Content type
application/octet-stream
Contents of the file

Get CLI document by name

This endpoint returns a document of help for the Run:ai CLI.

Authorizations:
bearerAuth
path Parameters
documentName
required
string [ 4 .. 255 ] characters ^[A-Za-z0-9_]+\.md$
Example: runai.md

The manual document name.

Responses

http://localhost:8080/api/v1/cli-exposer/docs/{documentName}
