# gocloak interface

This package contains a mockable Go interface (`GoCloak`) that mirrors the
public surface of the upstream [gocloak](https://github.com/Nerzal/gocloak)
client. Identity Manager depends on this interface — not on the concrete
gocloak struct — so that the Keycloak client can be substituted with a mock in
unit tests.

The interface in [`gocloak.go`](gocloak.go) is **generated** from the upstream
client by [`ifacemaker`](https://github.com/vburenin/ifacemaker) and must not
be edited by hand. Mocks under [`mocks/`](mocks) are generated from this
interface with [`mockery`](https://github.com/vektra/mockery).

## Regenerating the interface

When bumping the upstream gocloak version, regenerate `gocloak.go` as follows.

1. Pick the target gocloak version (e.g. `v13.9.0`) and check it out in a
   scratch directory:

   ```bash
   cd /tmp
   git clone git@github.com:Nerzal/gocloak.git
   cd gocloak
   git checkout <version>
   ```

2. Run `ifacemaker` against the upstream `client.go` to produce a new
   `gocloak.go`:

   ```bash
   ifacemaker \
     -f ./client.go \
     -s GoCloak \
     -i GoCloak \
     -p gocloak \
     -c "// DONT EDIT: Auto generated by https://github.com/vburenin/ifacemaker for more info see: README.md" \
     -o ./gocloak.go
   ```

3. Copy the generated `gocloak.go` over this directory's
   [`gocloak.go`](gocloak.go).

4. Update every import of `github.com/Nerzal/gocloak/<old-version>` in the
   repository to `github.com/Nerzal/gocloak/<new-version>` and run
   `go mod tidy`.

5. Regenerate the mocks (`go generate` from this directory, or rely on the
   repo-wide generation target).

## Why an interface?

Identity Manager touches a large portion of the gocloak surface (realms,
clients, users, identity providers, roles, …). Generating the interface from
the upstream source keeps that surface in sync mechanically and avoids drift,
while still giving us a single seam to mock when testing IAM-facing business
logic.
