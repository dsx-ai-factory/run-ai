Get users.

Retrieve a list of platform users.

Authorizations:
bearerAuth
query Parameters
filterBy
Array of strings[^((username|createdBy|lastLogin|creationTime|...]
Example: filterBy=username=@test,lastLogin>=2024-09-24T00:00:00.00Z,isLocal==false

Filter results by a parameter. Use the format field-name operator value. Operators are <= Less than or equal, >= Greater than or equal, =@ contains. Dates are in ISO 8601 timestamp format and available for operators <=, >= and ==.

sortBy
string (UsersFilterSortFields)
Enum: "username" "createdBy" "lastLogin" "creationTime" "lastUpdated" "type" "firstName" "lastName" "fullName"

Sort results by a parameters.

sortOrder
string
Default: "asc"
Enum: "asc" "desc"

Sort results in descending or ascending order.

offset
integer <int32>
Example: offset=100

The offset of the first item returned in the collection.

limit
integer <int32> [ 1 .. 500 ]
Default: 500

The maximum number of entries to return.

search
string
Example: search=test@run

Filter results by a free text search.

Get minimal user display information.

Retrieve a list of users with minimal display information (id, username, firstName, lastName). At least one of search, id, or filterBy is required to scope the lookup. Requires the users-minimal:read permission.

Authorizations:
bearerAuth
query Parameters
filterBy
Array of strings <= 25 items [^username(==|=@).+$]
Example: filterBy=username==test@run.ai

Filter results by username. Use the format field-name operator value. Supported operators are == (exact match) and =@ (contains). Multiple entries (up to 25) are allowed only with the == operator.

search
string [ 2 .. 100 ] characters
Example: search=john

Filter results by a free text search across username, firstName and lastName (OR logic). Minimum 2 characters.

id
Array of strings <= 25 items
Example: id=8e3f0a4b-4d3c-4f6e-9d2a-1c5e0a8b7f6d

Bulk lookup by user IDs (comma-separated). Returns the matching users in addition to any results from search or filterBy. Up to 25 IDs per request.

limit
integer <int32> [ 1 .. 500 ]
Default: 500

The maximum number of entries to return.

Responses

Use this endpoint to obtain an access token. Compliant with standard OAuth2 protocol and supports the common OAuth2 grant types.

Request Body schema: application/x-www-form-urlencoded
required
grant_type
required
string
Enum: "client_credentials" "password" "external_token_exchange"

The OAuth2 grant type. Determines the authentication flow and which parameters are required:

client_credentials - Authenticate as a service account or user access key using clientId and clientSecret.

password - Authenticate as a local user using username and password.

external_token_exchange - Authenticate as a service account or user using a token issued by the configured identity provider (IdP) for a Run:ai token. Requires externalToken.

client_id
string

The client identifier for a service account or user access key. Required when using the client_credentials grant type. Must be used together with clientSecret.

client_secret
string <password>

The client secret corresponding to the clientId. Required when using the client_credentials grant type. Must be used together with clientId.

username
string

The username of a local user account. Required when using the password grant type. Must be used together with password.

password
string <password>

The password for the specified username. Required when using the password grant type. Must be used together with username.

external_token
string

A valid token issued by the identity provider (IdP) that is configured in NVIDIA Run:ai. Required when using the external_token_exchange grant type.

refresh_token
string

The refresh token used to obtain a new access token. Required only when using the refresh_token grant type.

code
string

Authorization code issued by the authorization server. Used in the authorization_code grant to exchange the code for an access token.

redirect_uri
string

The redirect URI used during the authorization request. Required for the authorization_code grant to validate the redirect destination.

code_verifier
string^[A-Za-z0-9._~-]+$

PKCE code verifier. Required when the authorization code was requested with a code_challenge.
