# Support

## Supported Versions

We maintain the current release branch:

| Version | Status |
|---|---|
| `release-3.0` | Supported |

Bug reports and pull requests against unsupported branches are not accepted, except for critical security issues, which are handled privately via [GitHub Security Advisories](https://github.com/dsx-ai-factory/run-ai/security/advisories) (see [Security](SECURITY.md)).

When a new release ships, this section is updated to reflect the current supported branch.

## Where to Get Help

| Channel | Use it for |
|---|---|
| [GitHub Issues](https://github.com/dsx-ai-factory/run-ai/issues) | Bugs, feature requests, documentation issues, usage questions |
| [GitHub Security Advisories](https://github.com/dsx-ai-factory/run-ai/security/advisories) | Private vulnerability reports — see [Security](SECURITY.md) |

For commercial support and enterprise inquiries, contact NVIDIA at <https://www.nvidia.com/en-us/data-center/products/run-ai/>.
