# Support

## Supported versions

We maintain the latest 5 minor releases:

| Version | Status |
|---|---|
| `v2.26` | Supported |
| `v2.25` | Supported |
| `v2.24` | Supported |
| `v2.23` | Supported |
| `v2.22` | Supported |
| `v2.21` and earlier | End of life |

`v2.21` and earlier are end of life. Bug reports and pull requests against EOL branches are not accepted, except for critical security issues, which are handled privately via [GitHub Security Advisories](https://github.com/run-ai/runai/security/advisories) (see [`SECURITY.md`](SECURITY.md)).

When a new minor release ships, the oldest supported branch drops out of the list above and moves to EOL.

## Where to get help

| Channel | Use it for |
|---|---|
| [GitHub Issues](https://github.com/run-ai/runai/issues) | Bugs, feature requests, documentation issues, usage questions |
| [GitHub Security Advisories](https://github.com/run-ai/runai/security/advisories) | Private vulnerability reports — see [`SECURITY.md`](SECURITY.md) |

For commercial support and enterprise inquiries, contact NVIDIA at <https://www.nvidia.com/en-us/data-center/products/run-ai/>.
